# Crash locations (draft for Varsha)

Line numbers are `src/engine.py` (commit 686bbbb) unless another file is named.

- **Named hooks:** 14 rows (`crash.point` / `crash.torn_write_prefix`, triggered by `KVDB_CRASH=name:n`).
- **Other crash locations:** 4 rows marked "(no hook)". No test kills the process at those exact lines.

**Byte notation (README on-disk format):**

- `H` = the 16-byte header `"KVDB0001" | 01 00 00 00 | hcrc`.
- `F(..)` = a complete frame: `len u64 | crc u32 | nops u32 | ops`, where each op is `type u8 | klen u16 | vlen u32 | key | value`.
- `T` = a torn tail.
- "prev" = every frame committed before this operation.

**Next `open()`** is always `KVDB.__init__`:

1. `_flock`
2. `_open_file`: remove `.compact` / `.init`, then `_is_header_prefix` / `_create`
3. `_recover`: `mmap` + `check_header`
4. `_scan` → `format.decode_frame` → `_apply`
5. If `stop < size`: `ftruncate(stop)` + `fsync`

A row says only where this path differs from the clean path. **Torture seeds** below were run on 2026-11-06 on this machine (ext4, Arch Linux).
